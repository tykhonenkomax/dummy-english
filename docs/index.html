Англійські слова, які самі нагадують про себе

Запам'ятовуй слова без зубріння

Додавай слова й переклад — застосунок показуватиме їх на екрані з потрібною частотою.

  • Додавай слова та переклад

    у простій панелі керування.

  • Розподіляй слова за рівнем знання

    «Не знаю», «Вчу» або «Знаю».

  • Налаштовуй інтервали показу

    окремо для кожної групи слів.

  • Зберігай дані локально

    та експортуй резервну копію у файл.

Установлення

  1. Відкрий Dummy.English.dmg і перетягни застосунок у Applications.
  2. Під час першого запуску: правий клік → Open → Open. Якщо це не спрацює — System Settings → Privacy & Security → Open Anyway.
  3. Після запуску відкривай застосунок через значок у меню-барі.
