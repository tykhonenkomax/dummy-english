Встановлення

  1. Відкрий завантажений WordTrainer.dmg і перетягни іконку в Applications.
  2. Застосунок не підписаний сертифікатом Apple, тому при першому запуску звичайний подвійний клік не спрацює.
  3. Замість цього: правий клік (або Control+клік) на іконці → Open → у вікні, що з'явиться, ще раз натисни Open.
  4. Все, застосунок оселиться у меню-барі зверху екрана (значок "abc").
