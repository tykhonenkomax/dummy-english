# Dummy English

Menu bar застосунок для macOS, який показує англійські слова з перекладом
у вигляді спливаючої хмарки, поки ти працюєш.

- Додаєш слова в адмінці, розподіляєш по трьох колонках: «Погано знаю»,
  «Середньо», «Добре знаю».
- Для кожної колонки окремо виставляєш, як часто слово з неї спливатиме на
  екрані (у випадковому куті).
- База зберігається локально в `~/Library/Application Support/WordTrainer/`.
  Кнопки «Експорт бази…» / «Імпорт бази…» дозволяють зберегти
  `wordtrainer-backup.json` (наприклад, у Dropbox) і підтягнути його назад
  після переустановки системи.

## Встановлення (готовий білд)

1. Завантаж `WordTrainer.dmg` з розділу [Releases](../../releases).
2. Відкрий DMG, перетягни `WordTrainer.app` в Applications.
3. Застосунок **не підписаний** сертифікатом Apple Developer (він коштує
   грошей), тому за замовчуванням Gatekeeper не дасть його відкрити.
   Один раз зроби одне з двох:
   - Правий клік на іконці → **Open** → підтвердити у вікні, що з'явиться;
   - або в терміналі: `xattr -cr /Applications/WordTrainer.app`
4. Після цього застосунок відкривається звичайним подвійним кліком і сидить
   у menu bar (іконка "abc").

## Збірка з коду

Потрібен Xcode / Command Line Tools (Swift 5.10+).

```bash
git clone <this repo>
cd word-trainer
./build-app.sh
```

Скрипт збере реліз, спакує `dist/WordTrainer.app` і `dist/WordTrainer.dmg`.
